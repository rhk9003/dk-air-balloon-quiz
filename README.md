# DK 空氣鞋知識小樂園

跟著 DK 高博士的呼吸小氣球，一起完成 5 題空氣鞋互動問答，認識得獎紀錄與底台技術。

遊戲適合手機操作，提供答案解說、答題結果及重點複習，不需登入。

## 網站

- [開始遊戲](https://rhk9003.github.io/dk-air-balloon-quiz/)
- [認識 DK 高博士空氣鞋](https://www.dk-shoes.com.tw/page/AirShoes)

## 執行方式

以原生 HTML、CSS、JavaScript 製作，無須建置或安裝套件。可直接開啟 `index.html`，或透過一般靜態網站伺服器提供服務。

GitHub Pages 使用 `main` 分支的根目錄發佈。
